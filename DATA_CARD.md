# Data card

## Distributed data

Only three synthetic example documents and one synthetic query are included. They were written for this code example and are not copied from the project's medical datasets.

## Non-distributed research inputs

The private research workspace used processed Korean medical examination questions, AIHub QA-derived assets, and other medical QA/parallel-text resources under dataset-specific terms. MIMIC-derived row-level content, raw datasets, review packets, and all licensed source payloads are excluded.

## Aggregate results

`results/benchmark_summary.json` contains model-level numeric aggregates only. It contains no question text, passage text, query identifier, qrel, answer label, or embedding vector.

## Responsible use

Users must obtain each source dataset independently and comply with its license and access terms. Nothing in this repository relicenses third-party data.
